# ScholarSpace — Student Study Dashboard

## About the Project

ScholarSpace is a student-focused website designed to help students organize their academic activities in one place. It provides a simple and welcoming interface for viewing courses, tracking assignments, and keeping study activities organized.

The goal of ScholarSpace is to make studying more organized, productive, and manageable.

## Features

- **Home Page:** Introduces ScholarSpace and highlights its main features.
- **Student Dashboard:** Provides an overview of study activities.
- **Course Cards:** Displays course information in an organized layout.
- **Assignment Section:** Helps students view and organize their assignments.
- **Study Schedule:** Presents study activities and scheduled sessions.
- **Study Goals:** Provides a section for tracking learning goals.
- **Responsive Styling:** CSS styling helps the interface adapt to different screen sizes.

## Technologies Used

- **HTML5** — Structures the web pages.
- **CSS3** — Styles the website, including layouts, colors, typography, and responsive design.
- **Git** — Tracks changes to the project.
- **GitHub** — Hosts the repository and supports collaboration.

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/roxaneisaro12/scholar-space.git
   ```

2. Open the project folder:

   ```bash
   cd scholar-space
   ```

3. Open `index.html` in a web browser, or open the project in Visual Studio Code and use the Live Server extension.

4. To view the dashboard directly, open `dashboard.html` in your browser.

## Git Workflow

The project uses Git branches to organize development work.

- `main` — Contains the integrated project.
- `feature/dashboard` — Used to develop and improve the dashboard.
- `feature/home-page` — Used to develop the home page.

Changes are committed and pushed to GitHub, then integrated into `main` when ready.

## Project Goal

ScholarSpace aims to provide a clear and user-friendly starting point for students who want to organize their courses, assignments, schedules, and study goals.
